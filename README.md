# Reselect

## Запуск

Встановіть залежності та запустіть API і веб-додаток в різних терміналах:

```bash
npm install
npm run server
npm start
```

API доступний на `http://localhost:4040`, а додаток — на
`http://localhost:3000`.

## GitHub Pages

Для публикации соберите и отправьте статическую сборку в ветку `gh-pages`:

```bash
npm run deploy
```

Сайт будет доступен на
`https://windybindy.github.io/Reselect/`.
